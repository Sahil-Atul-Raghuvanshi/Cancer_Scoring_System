# Extra packages the training notebooks need, on top of the demo backend's own
# requirements.txt and requirements-qc.txt.
#
# Install into the BACKEND's virtualenv, not a new one:
#
#     cd Breast_Cancer_IHC_Tissue_Scoring_Demo\backend
#     .venv\Scripts\python -m pip install -r ..\..\bcss_bracs_hchannel_resnet18\requirements.txt
#
# One interpreter is the point. Everything here imports the pipeline's own colour
# deconvolution - `app.common.stains`, `step06_colour_deconvolution` - so that the
# model is trained on the same haematoxylin channel it will be served. A separate
# venv would make `import app.*` a path trick rather than the real thing.
#
# Already present from the backend and deliberately NOT repeated here, so there is
# one place each version is pinned: torch (2.8.0+cpu), torchvision (0.23.0+cpu),
# numpy, Pillow, scipy, tifffile, tiffslide, tqdm, pytest.
#
# Do NOT upgrade torch to satisfy a notebook. requirements-qc.txt records why:
# torch >= 2.9 unpacks a licence tree deep enough to exceed MAX_PATH under this
# project's path, and pip fails mid-install leaving a torch that cannot be cleanly
# uninstalled.

# --- notebooks ---------------------------------------------------------------

# class of problem requirements-qc.txt records for torch >= 2.9.
#

# the identical code from the command line - which is how the models in

# to read the notebooks interactively, and then either enable long paths
#
#     Set-ItemProperty -Path 'HKLM:\SYSTEM\CurrentControlSet\Control\FileSystem' `
